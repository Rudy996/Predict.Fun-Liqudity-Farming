# Predict Fun Liquidity Provider

## Установка

1. Установите **Python** 3.11+.
2. Установите **Node.js** LTS (**npm** входит в установку).
3. Склонируйте репозиторий и откройте папку проекта в терминале.
4. Зависимости Python:
   ```bash
   pip install -r requirements.txt
   ```
5. Зависимости интерфейса:
   ```bash
   cd electron-ui
   npm install
   cd ..
   ```
6. Запуск:
   ```bash
   python main.py
   ```
